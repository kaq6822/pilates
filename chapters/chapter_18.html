Chapter 18. Case Study와 실제 회원 평가

1. 학습목표

  1. 회원정보를 받아 운동 가능 여부와 수정 필요성을 체계적으로 판단한다.
  2. ‘주수별 정답 프로그램’ 대신 개별 사례에 맞는 목표를 설정한다.
  3. Green / Yellow / Red 분류를 적용한다.
  4. 각 사례에서 운동선택, 수정, 의뢰기준을 설명한다.

2. Case Study 사고 공식

모든 사례에서 다음 8단계를 사용한다.

  1. Medical/Safety — 운동 가능한가?
  2. Symptoms — 현재 증상은?
  3. History — 운동경력은?
  4. Function — 일상에서 무엇이 어려운가?
  5. Goals — 무엇을 개선/유지할 것인가?
  6. Dose — 어느 정도 부하가 적절한가?
  7. Modification — 어떤 변수를 바꿀 것인가?
  8. Referral — 언제 전문가에게 보낼 것인가?

Case 1. 임신 10주 / 운동경험자 / 심한 피로

정보

  • 31세
  • Reformer 4년
  • 산과적 특이사항 없음
  • 오심은 약간, 피로가 심함

분류

🟢 Green, 당일 autoregulation 필요.

목표

근력 유지, 과도한 피로 방지.

계획

  • 40분 세션
  • 주요 strength 앞쪽 배치
  • RPE 11~13
  • 긴 휴식

교육

임신 초기 피로는 체력저하만으로 설명하지 않는다.

Case 2. 임신 18주 / 완전 초보

정보

  • 36세
  • 운동 거의 없음
  • 합병증 없음
  • 허리 피로 호소

분류

🟢 Green.

목표

기본 movement confidence, lower-body/upper-back strength.

계획

  • footwork low-moderate
  • seated row
  • supported squat
  • side-lying hip
  • breathing

진행

2~4주 동안 volume을 점진적으로 증가.

Case 3. 임신 22주 / supine dizziness

정보

Footwork 5분 후 어지럼·오심, 옆으로 돌아누우면 회복.

분류

해당 자세에 🟡 modification. 지속/심화 시 의료확인.

계획

  • supine block 종료
  • side-lying leg press
  • seated upper body
  • quadruped trunk

핵심

supine에 ‘적응’시키려 하지 않는다.

Case 4. 임신 25주 / Coning

정보

Double-leg tabletop + chest lift에서 뚜렷한 coning, 통증 없음.

목표

trunk strength 유지.

🛠 실전 적용

수정

  • head support
  • single-leg tabletop
  • elevated plank
  • quadruped arm/leg reach

설명

coning을 조직손상이라고 겁주지 않는다.

Case 5. 임신 27주 / 치골통증

정보

걷기, 침대 돌아눕기, standing scooter에서 통증.

분류

🟡 PGP 가능성 — 강사가 진단하지 않음.

계획

  • bilateral footwork
  • narrow squat
  • side-lying small ROM
  • large split stance 감소

의뢰

일상기능이 제한되므로 pelvic-health/MSK physio 평가 권고.

Case 6. 임신 29주 / 요실금

정보

기침과 강한 squat에서 소량 누출.

분류

🟡.

계획

  • breath holding 확인
  • load/depth 조정
  • 기본 PFMT awareness
  • 증상 기록

의뢰

pelvic-health physiotherapist 권고.

Case 7. 임신 30주 / Pelvic Heaviness

정보

standing circuit 15분 후 “밑이 빠질 듯 묵직함.”

계획

  • standing volume 축소
  • seated/side-lying 비중 증가
  • heavy spring 감소
  • exhale on effort

의뢰

반복 시 전문평가.

Case 8. 임신 31주 / 쌍둥이

정보

운동을 계속하고 싶음. 현재 산과적 상태를 강사가 모름.

분류

🟡 현재 산과 상태가 불명확하므로 확인 우선. 쌍둥이 자체를 자동 Red로 분류하지 않는다.

계획

주수, 태반·자궁경부·성장·조산 관련 이슈, 담당 산과의 활동제한을 확인한 뒤 설계한다. 특히 후기 다태임신은 의료진과의 협업이 중요하다.

핵심

“쌍둥이니까 무조건 금지”도, “Pilates니까 무조건 괜찮음”도 아니다. 다태임신의 분류는 지침과 임상상태에 따라 달라질 수 있으므로 강사가 단어 하나로 결정하지 않는다.

Case 9. 임신 33주 / 한쪽 종아리 통증·부종

정보

오른쪽 종아리만 붓고 아프며 따뜻한 느낌.

분류

🔴 Red.

대응

  • 운동하지 않음
  • massage/stretch 하지 않음
  • 즉시 의료평가 안내

Case 10. 임신 34주 / 높은 체력

정보

웨이트·Pilates 8년, 정상 임신, 증상 없음. 저강도 stretching만 받아 답답함.

분류

🟢 Green.

목표

의미 있는 strength 유지.

계획

  • RPE 12~14 중심
  • moderate resistance
  • supported functional strength
  • balance risk는 불필요하게 높이지 않음

Case 11. 임신 35주 / 수면부족

정보

산과적 문제 없음. 3시간밖에 못 잠.

분류

🟢이나 readiness 낮음.

계획

  • volume 20~30% 감소
  • standing challenge 감소
  • 35~40분 세션

Case 12. 임신 36주 / 심한 두통+시야 흐림

분류

🔴 Red.

대응

운동을 하지 않는다. 임신 중 심한 두통과 시야 변화는 긴급한 maternal warning sign이 될 수 있어 즉시 의료진 평가를 안내한다.

Case 13. 임신 37주 / 태동 감소 호소

정보

“오늘 아기가 평소보다 거의 움직이지 않는 느낌.”

분류

🔴 Red.

대응

수업보다 산과 의료진 확인이 우선. 운동으로 태동을 유도하려 하지 않는다.

Case 14. 임신 24주 / 손목통증

정보

Quadruped 30초 후 손저림·손목통증.

계획

  • forearm on box
  • seated trunk work
  • wrist extension loading 감소

의뢰

지속·근력저하가 있으면 의료진/물리치료 평가.

Case 15. 임신 28주 / reflux

정보

식후 supine에서 속쓰림.

계획

  • 상체 elevation
  • seated/standing 비중 증가
  • 식사 직후 intense trunk work 피하기

약물·식이처방은 하지 않는다.

Case 16. 임신 24주 / 고강도 근력운동 숙련자 / Valsalva 질문

정보

  • 8년간 웨이트트레이닝
  • 정상 임신, 증상 없음
  • “무거운 squat에서 잠깐 숨을 참는 것도 무조건 위험한가요?”

분류

🟢 일반 활동은 가능하나, 최대노력/고중량 영역은 근거 한계를 설명하고 개별화.

지도

  • 짧은 자연스러운 bracing을 공포로 설명하지 않는다.
  • 2025년 급성 연구들은 숙련된 건강한 임산부의 heavy/high-intensity resistance exercise가 자동으로 위험하다고 단정할 근거는 약하다는 점을 보여주지만, 장기 안전 상한을 정하지는 못했다.
  • Valsalva를 직접 포함한 연구는 매우 작았고, 더 큰 heavy-load 연구에서는 Valsalva가 기록되지 않았으므로 “반복적 Valsalva가 검증되었다”고 설명하지 않는다.
  • Pilates 세션에서는 free breathing 가능한 submaximal load를 기본으로 한다.
  • 기록경신·1RM 테스트를 산전 Pilates의 progression으로 삼지 않는다.
  • 고강도 스포츠 훈련을 계속할 경우 담당 산과의료진 및 관련 전문 코치와 협업을 권한다.

Case 17. 임신 30주 / 운동 중 coning은 보이지만 무증상

정보

Elevated plank에서 중앙 돌출이 약간 보이지만 통증·누출·heaviness 없음. breathing 가능.

분류

🟢/🟡 코칭 modification 영역. 손상으로 진단하지 않는다.

계획

  • box height를 조금 높여 반응 확인
  • hold time을 줄여 fatigue effect 확인
  • 증상과 기능을 함께 기록
  • coning “0”만을 목표로 만들지 않는다.

Case 18. 임신 26주 / 심한 우울감과 자해 생각 언급

정보

수업 전 “사라지고 싶고 나를 해칠 생각이 든다”고 말함.

분류

🔴 Urgent maternal warning sign.

대응

운동수업을 진행하지 않는다. 혼자 감당하도록 두지 말고 지역의 즉시 의료/정신건강 응급지원 및 산과의료진으로 연결한다. 임박한 위험이 있으면 응급의료체계를 이용한다. 강사가 상담치료를 대신하지 않는다.

3. Green / Yellow / Red의 한계

이 색분류는 교육용 의사결정 휴리스틱이며 검증된 의료진단 도구가 아니다. 실제 임신운동 금기와 screening은 CSEP GAQ-P/HCP form, 담당 산과의 지시, 지역 규정 등 공식 체계를 우선한다.

4. 실습 과제

각 사례에서 다음을 작성한다.

  • Green/Yellow/Red
  • 오늘 수업 가능 여부
  • 3가지 운동목표
  • 선택할 5개 운동
  • 피하거나 수정할 3개 변수
  • 의뢰 기준

5. 모범 사고의 특징

좋은 답은 “몇 주에는 무엇을 금지”만 쓰지 않는다.

좋은 답은 다음을 포함한다.

  • 회원의 운동경력
  • 현재 증상
  • 운동의 목적
  • 수정 순서
  • 의료진 경계
📌 반드시 기억

6. 핵심정리

Case study는 지식을 실제 판단으로 바꾸는 단계다. 산전 전문가의 핵심은 주수를 보고 운동목록을 떠올리는 것이 아니라, 회원정보를 보고 위험·목표·부하·수정을 동시에 설계하는 능력이다.
