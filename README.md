# 필라테스 교육 아카이브

정적 HTML 기반의 필라테스 지도 교육 사이트입니다. 로컬에서는 프로젝트 루트에서 정적 서버를 실행한 뒤 `index.html`을 엽니다.

## 구조

- `index.html`: 교육 과정 목록과 시작 페이지
- `chapters/`: 기존 산전 필라테스 과정의 챕터별 학습 페이지
- `courses/`: 앞으로 추가할 독립 교육 과정
- `assets/css/`: 공통 스타일
- `assets/js/`: 목차 생성과 화면 보정 스크립트
- `archive/`: 한 파일로 합친 전체본

새 과정의 폴더 구조와 추가 순서는 [courses/README.md](courses/README.md)를 참고합니다.
