# 교육 과정 추가 안내

이 프로젝트의 첫 화면은 과정 목록입니다. 새 교육 주제는 기존 산전 과정의 챕터에 섞지 않고, 독립된 과정 폴더로 추가합니다.

## 권장 구조

```text
courses/
  postpartum/
    index.html          # 과정 소개와 챕터 목차
    chapter_01.html
    chapter_02.html
    assets/             # 해당 과정에만 필요한 이미지·자료 (선택)
```

공통 스타일과 동작은 기존 `assets/css/style.css`, `assets/js/app.js`를 재사용합니다. 과정 내부 파일에서 공통 자산을 불러올 때는 `../../assets/...`처럼 상대 경로를 맞춥니다.

## 새 과정 체크리스트

1. `courses/<과정-slug>/index.html`에 과정 소개, 대상, 학습 목표, 챕터 링크를 작성합니다.
2. 각 챕터는 독립 HTML 파일로 만들고, 과정 목차로 돌아가는 링크를 둡니다.
3. `index.html`의 “현재 학습할 수 있는 과정” 영역에 과정 카드를 추가합니다.
4. 과정이 아직 공개 전이면 “추가될 교육 과정” 영역에만 표시하고 링크를 만들지 않습니다.

## 현재 산전 필라테스 과정

기존 산전 필라테스 과정은 이전 주소 호환성을 위해 `chapters/`에 유지합니다. 새로 만드는 과정부터 위의 `courses/<과정-slug>/` 구조를 사용합니다.
