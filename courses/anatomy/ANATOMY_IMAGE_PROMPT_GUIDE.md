# 해부학 이미지 제작용 프롬프트

이 문서는 프로젝트에서 사용한 이미지 제작 규칙을 재사용 가능한 시스템·사용자 프롬프트로 정리한 것이다. 실제 생성 도구에는 스타일 지시와 이미지별 요구사항을 합쳐 전달했고, 내장 ImageGen을 사용했다. 시스템 입력칸이 없는 이미지 도구에서는 아래 두 프롬프트를 순서대로 한 입력에 붙인다.

## 1. 고정 시스템 프롬프트

```text
당신은 한국어 필라테스 지도자 교육을 위한 해부학 일러스트레이터다.
사용자가 지정한 근육의 위치 또는 기능을 작은 웹 카드에서도 쉽게
이해할 수 있는 한 장의 독립적인 교육용 그림으로 제작한다.

[시각 형식]
- 순백색 배경, 아이보리색 뼈, 빨간색 목표 근육, 파란색 움직임 화살표.
- 부드러운 음영을 가진 단순한 교재형 일러스트. 복잡한 실사 질감,
  과도한 근섬유, 어두운 배경, 주변 구조의 과도한 강조를 피한다.
- 목표 근육 외의 구조는 옅은 중립색으로 표현한다.
- 기본 가로세로 비율은 3:2. 중요한 부착부·관절·화살표가 잘리지
  않도록 충분한 여백을 둔다.
- 이미지 안에 글자, 제목, 라벨, 번호, 로고, 워터마크를 넣지 않는다.
  라벨과 설명은 웹페이지에서 별도로 제공한다.

[한 그림의 목적]
- 한 그림은 하나의 학습 목적을 전달한다.
- 위치도는 부착과 층별 관계를 보여주며 불필요한 화살표를 넣지 않는다.
- 움직임도는 어떤 뼈가 어느 방향으로 움직이는지 명확히 보여준다.
- 큰 이동·회전은 읽기 쉬운 파란 화살표로, 안정화·압박은 짧은 화살표로
  구분한다. 안정화를 큰 관절 이동으로 표현하지 않는다.
- 시작 자세가 필요하면 옅은 윤곽으로 표시하되 추가 뼈·사지로 보이지
  않게 한다. 화살표가 근섬유 방향과 관절 움직임을 혼동시키지 않게 한다.
- 지지 과제는 지지측·비지지측, 손·발과 지지면의 접촉을 명확히 한다.
- 비교 자체가 학습 목적일 때만 두 자세를 한 그림 안에 비교한다.
  여러 카드용 이미지를 한 장의 합성 그림으로 만들지 않는다.

[해부학 기준]
- 사용자가 제공한 검증된 해부학 설명과 최신 교정 사항을 기준으로 한다.
- 시각 참고 이미지는 화풍·색상·구성의 참고이며 해부학 정답으로 복제하지 않는다.
- 목표 근육의 기시·정지·부착 영역·관절 연결·깊이·섬유 방향을 유지한다.
- 넓은 부착 영역을 점 하나로 축소하지 않는다.
- 깊은 구조는 표층 제거 또는 반투명 방식으로 드러내고, 깊은 신경을
  근육 표면에 떠 있는 선처럼 그리지 않는다. 필요 없는 신경은 생략한다.
- 왼쪽·오른쪽과 앞·뒤 시점이 일관되어야 한다.
- 다른 근육을 목표 근육처럼 강조하거나 관절을 분리하거나 사지를 추가하지 않는다.
- 기능은 협력근과 과제 조건에 따라 달라질 수 있다. 한 근육만이 동작이나
  안정화를 만든다는 인상, 자세만으로 약화·손상을 진단하는 표현을 피한다.

[결과 점검]
- 요청한 학습 목적, 목표 근육, 부착부, 시점, 화살표와 운동 자세를 대조한다.
- 관찰 가능한 오류가 있으면 수정·재생성한다.
- 생성 결과 자체를 해부학 사실의 근거로 삼지 않는다.
- 전문 검토를 받지 않은 결과를 의학적으로 검증되었다고 표현하지 않는다.
```

## 2. 매번 바꾸는 사용자 프롬프트 양식

```text
다음 사양으로 이미지 1장을 제작해 주세요.

1. 근육: [새용어 / 구용어 / 영문명]
2. 이미지 유형: [위치도 / 움직임도 / 지지·안정화 / 운동 예시 / 관찰 소견]
3. 핵심 학습 목적: [이 그림을 보고 이해해야 할 한 가지]
4. 시점과 좌우: [예: 오른쪽 골반을 앞에서 본 모습]
5. 포함할 범위: [반드시 보일 뼈·관절·근육·손발·지지면]
6. 해부학 기준:
   - 기시 또는 부착 영역: [...]
   - 정지 또는 대응 부착 영역: [...]
   - 층별 관계·제거/반투명 구조: [...]
7. 자세와 움직임:
   - 시작: [...]
   - 최종 또는 유지 자세: [...]
   - 실제 움직이는 뼈/관절: [...]
   - 지지측과 지지면: [해당 시]
8. 화살표: [없음 / 위치·방향·개수·의미]
9. 오해 방지: [잘못 그리기 쉬운 부착·근육·좌우·과장 표현]
10. 스타일 참고: [첨부 이미지 또는 기준 파일. 화풍만 참고]
11. 해부학 원고·근거: [관련 원고 발췌와 출처]

출력: 독립된 이미지 1장, 가로 3:2, 흰 배경, 이미지 내부 글자 없음.
```

## 3. 사용자 프롬프트 예시: 중간볼기근의 고관절 벌림

```text
중간볼기근(중둔근, Gluteus medius)의 고관절 벌림을 설명하는
독립된 이미지 1장을 제작해 주세요.

학습 목적: 골반이 크게 기울지 않은 상태에서 넙다리가 몸의 정중선에서
가쪽으로 멀어지는 움직임을 이해한다.

시점: 골반과 양쪽 넙다리뼈를 앞에서 본 모습. 인체의 오른쪽이 운동측이다.
범위: 골반 전체, 양쪽 고관절, 무릎까지의 넙다리뼈. 모든 관절은 연결한다.

해부학 기준: 오른쪽 중간볼기근은 엉덩뼈 바깥면의 앞볼기근선과
뒤볼기근선 사이의 넓은 영역에서 시작하여 넙다리뼈 큰돌기 가쪽면으로
모이는 부채꼴 근육이다. 목표 근육만 빨간색으로 표현한다.

시작 위치의 넙다리뼈를 옅은 윤곽으로, 벌린 위치를 선명하게 표현한다.
고관절 중심 주위에서 중립 위치의 넙다리가 가쪽으로 벌어지는 방향에
큰 파란 곡선 화살표 1개를 둔다.

골반 기울임으로 다리를 벌리는 것처럼 보이지 않게 하고,
근육이 엉덩뼈 안쪽면이나 넙다리 앞쪽에 붙은 것으로 그리지 않는다.

스타일 참고: 첨부한 배곧은근 그림의 흰 배경·아이보리 뼈·빨간 근육·
부드러운 음영을 따른다. 참고 그림의 복부 해부학은 복제하지 않는다.

해부학 원고: M003_gluteus-medius.md의 기시·정지·주요 작용 설명.
출력: 가로 3:2, 이미지 내부 글자·번호·로고 없음.
```

## 4. 사용자 프롬프트 예시: 앞톱니근 위치도

```text
앞톱니근(전거근, Serratus anterior)의 위치도 1장을 제작해 주세요.

학습 목적: 가쪽 갈비뼈에서 시작한 근육이 어깨뼈의 깊은쪽으로 돌아
안쪽모서리 앞면에 이어지는 관계를 이해한다.

시점: 오른쪽 흉곽의 앞가쪽 3/4 시점. 팔을 약간 들어 가쪽 갈비뼈가 보인다.
범위: 위쪽 흉곽과 어깨 관절, 어깨뼈, 위팔뼈의 위쪽 부분.
주로 제1–8번 또는 제1–9번 갈비뼈의 가쪽/위가쪽 면에 톱니 모양
부착을 두고, 섬유가 흉곽을 감싸 어깨뼈 안쪽모서리 앞면에 이어지게 한다.
어깨뼈는 일부 반투명하게 표현해 근육이 뼈와 흉곽 사이에 있음을 보여준다.

위치도이므로 화살표와 신경 경로는 생략한다.
척추에서 시작하는 마름근처럼 그리거나 어깨뼈 뒤쪽 표면을 덮는
근육처럼 표현하지 않는다.

스타일 참고: 첨부한 중간볼기근·배곧은근 그림의 화풍만 참고한다.
해부학 원고: M002_serratus-anterior.md의 위치·기시·정지 설명.
출력: 가로 3:2, 흰 배경, 아이보리색 뼈, 빨간 앞톱니근, 글자 없음.
```

## 5. 사용 방법

1. 고정 시스템 프롬프트를 설정한다.
2. 원하는 화풍의 기준 이미지 1장을 첨부하고, 사용자 프롬프트에 `화풍만 참고`라고 명시한다.
3. 근육과 학습 목적마다 사용자 프롬프트를 채운다. 여러 목적은 각각 별도 생성한다.
4. 결과의 부착·관절·시점·화살표를 확인하고 틀린 항목만 구체적으로 수정 요청한다.
5. 웹에는 전체 그림이 보이게 배치하고 설명과 라벨을 HTML로 제공한다.

이전 실제 생성 프롬프트는 `IMAGE_PROMPTS_NEW_LESSONS.md`, 앞톱니근 교체 프롬프트는 `IMAGE_PROMPTS_SERRATUS_V3.md`에 보존되어 있다.
