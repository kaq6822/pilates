# 필라테스 해부학 과정

97개 근육·근육군의 정적 학습 페이지와 총 970개 학습 확인 문제를 제공합니다.
각 페이지는 주요 이해, 해부학 상세, 움직임과 기능, 필라테스 적용, 퀴즈의 5개 탭으로 구성됩니다.

## 콘텐츠와 빌드

- `content/M###_*.md`: 제공된 v5 원고. 기존 원고는 덮어쓰지 않고 누락된 94개 원고를 원본 묶음에서 가져왔습니다.
- `content/lesson_overrides.json`: 배곧은근·중간볼기근의 화면용 카드 및 선택형 퀴즈 데이터.
- `templates/serratus.html`: 앞톱니근의 기존 수동 편집 본문을 보존한 템플릿.
- `scripts/build_lessons.py`: 기존 두 페이지 렌더링 후 전체 과정 빌드 실행.
- `scripts/full_course.py`: 나머지 94개 원고 렌더링, 전체 탐색·목록 생성, 이미지 빈 영역 처리.

```sh
python3 courses/anatomy/scripts/build_lessons.py
```

새 페이지는 원고의 교육 내용(1–9절)과 근거 자료(12절)를 탭에 배치합니다. 10절의 이미지 제작 명세는 원고에 보존하며 학습 화면에는 표시하지 않습니다. 퀴즈는 11절의 10문항과 정답을 바탕으로 만든 4지선다(참·거짓 문항은 2지) 객관식입니다. 객관식 데이터는 `content/quiz_choices/M###.json`에 원고와 분리해 두며, 빌더가 강의별로 정답 위치를 고르게 섞습니다. 보기를 선택하면 정답·오답 표시와 해설이 바로 열리고, JavaScript가 없어도 ‘정답·해설 보기’로 확인할 수 있습니다. 선택 결과는 저장하지 않습니다.

## 화면과 접근성

부위별 목록, 새용어·구용어·영문명·부위 검색, 이전·다음 학습, 모바일 근육 탐색을 제공합니다. 탭과 정답 해설은 JavaScript 없이도 동작하며 검색과 선택형 즉시 피드백만 JavaScript를 사용합니다. API·DB·로그인·영구 학습 저장은 없습니다.

사용자 요청에 따라 모든 학습 이미지 영역을 비워 두었습니다. 기존 이미지 파일과 제작 기록은 보존하며 생성 HTML에서 로드하지 않습니다.

## 확인

97개 페이지의 5개 탭, 각 10문항, 중복 ID, 로컬 링크 및 이미지 미참조를 검사했습니다. Chrome에서 데스크톱(1440px)·모바일(390px)의 검색·학습 이동·탭·정답 펼치기와 대표 페이지의 가로 넘침, JavaScript 비활성 상태의 탭·해설 접근을 확인했습니다. 이 검사는 구현 확인이며 전문 해부학 감수가 아닙니다.
