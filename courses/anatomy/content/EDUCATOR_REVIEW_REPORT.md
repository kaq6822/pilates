# 교육자 관점 교차검토 보고서 v3

## 검토 범위

97개 개별/근육군 MD 전체를 다음 다섯 축으로 다시 검토했다.

1. 해부학 정확도와 변이 표현
2. 한글 새용어/구용어 통일
3. Pilates 적용의 교육적 깊이
4. 근육별 퀴즈 확장
5. SVG용 뼈·연부조직 landmark 세분화

## 해부학

기시·정지·신경·작용은 각 원고의 NCBI/StatPearls 중심 출처를 기준으로 유지하면서, 오류 가능성이 큰 항목을 추가 교차검증했다. 특히 척주세움근 구획, 목갈비근, 항문올림근 신경지배, 깊은 고관절 회전근, 큰모음근, 장딴지근, 갈비사이근, 발의 작은 근육을 중점 재검토했다.

확정하기 어려운 신경근 분절이나 부착 변이는 '자료마다 다름'으로 뭉뚱그리지 않고 **무엇이 확실하고 무엇이 변이인지**를 분리했다.

## 용어

제목은 `새용어 (구용어) · English`, 본문은 새용어 우선으로 통일했다. 구용어는 frontmatter/search alias로 보존한다. 상세 기준은 `TERMINOLOGY_POLICY.md`, 전체 대응표는 `TERMINOLOGY_GLOSSARY.md`에 있다.

## Pilates 적용

이전 버전의 부위별 공통 문구를 더 세분화했다. 예를 들어 어깨는 `어깨뼈 (견갑골) 움직임근 / 위팔뼈 (상완골) 주동근 / 회전근개`, 고관절은 `엉덩허리근 / 볼기근 / 깊은 회전근 / 모음근`, 하지는 `넙다리네갈래근 / 햄스트링 / 발바닥굽힘근 / 발등굽힘근 / 발 내재근` 등으로 구분했다.

모든 적용 섹션은 특정 근육을 '사용하거나 과도한 사용을 줄이는' 접근보다 `관절 위치, 레버, 외부부하, 지지면, 호흡, 증상`을 조절하는 방향으로 작성했다.

## 퀴즈

모든 97개 페이지를 **8문항**으로 확장했다. 여러 구획이 있는 근육은 구획명을 질문에 명시했고, 갈비사이근처럼 연속 부착 구조는 억지로 기시/정지로 단순화하지 않았다. 총 문항 수는 **776문항**이다.

## SVG

모든 페이지에 `기본 시점 / 필수 부착 landmark / 깊이·인접 관계 / 움직임 표시 / 10개 레이어 ID / 기존 비주얼 포인트 / 오해 방지`를 명시했다. 힘줄·근막 등 비골성 부착은 별도 레이어로 분리했다.

## 공개 전 마지막 검수 항목

문서 콘텐츠 검수와 실제 그림 검수는 다르다. SVG가 제작되면 기시·정지 hotspot의 실제 위치, 표층/심층 순서, 좌우 방향, 신경 경로를 최종 이미지 기준으로 한 번 더 검수해야 한다.
