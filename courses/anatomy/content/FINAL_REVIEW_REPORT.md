# 최종 교육자 검토 보고서 v5

## 이번 최종 검토에서 실제로 발견한 사항

1. **v4 QA와 실제 원고가 일치하지 않는 표현이 있었다.** `켜다/끄다` 비유가 일부 주의 문장에 남아 있어 문맥에 맞게 `사용한다 / 사용 여부 / 과도한 사용을 줄인다` 계열로 수정했다.
2. **상시 뼈 병기 자동 치환의 부작용이 있었다.** `관자뼈` 내부의 `자뼈`가 잘못 치환된 사례와 골반저 근육 별칭이 분해된 사례를 수정했다.
3. **퀴즈 기준이 최신 합의와 불일치했다.** 8문항에서 10문항으로 변경하고, 관절/분절 움직임 해석과 Pilates 움직임 적용 문항을 각 1개씩 추가했다.
4. **영어 전문용어 처리 규칙을 명시했다.** 문제 풀이에 필요한 영어는 한국어 우선 표기 후 문제 아래 `용어 설명`을 제공한다.
5. **앞톱니근 용어를 학습 친화적으로 수정했다.** `전인/상방회전` 대신 `내밈(protraction)/위쪽돌림(upward rotation)`을 사용하고 `winging`은 `날개어깨(scapular winging)`로 설명한다.

## 해부학 검증 메모

앞톱니근의 대표 기시는 제1–8 또는 제1–9 갈비뼈 가쪽면, 정지는 어깨뼈 안쪽모서리의 앞면이며 긴가슴신경(C5–C7)이 주된 신경지배다. 주요 기능은 어깨뼈 내밈과 위쪽돌림 및 흉곽에 대한 어깨뼈 유지로 정리하는 것이 적절하다.

## 웹 구현 전 콘텐츠 상태

이 버전은 정적 웹 프로토타입에 연결할 수 있는 수준으로 구조를 정리했다. 다만 실제 의료·교육 출판 수준의 최종 배포 전에는 97개 페이지의 개별 해부학 사실을 전문 해부학자/의료전문가가 독립적으로 교열하는 절차를 권장한다.
