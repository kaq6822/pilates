# SVG 해부학 제작 공통 규격 v3

각 근육 MD의 `## 10. 웹 해부학 비주얼 요구사항`을 우선한다.

## 공통 레이어

- `skeleton-base`
- `target-muscle`
- `origin-hotspot`
- `insertion-hotspot`
- `tendon-fascia`
- `adjacent-muscles`
- `nerve-path`
- `motion-arrows`
- `labels`
- `quiz-hotspots`

## 제작 원칙

1. 기시·정지는 색뿐 아니라 O/I 또는 몸쪽/먼쪽 부착 표식으로 구분한다.
2. 깊은 근육은 표층 구조를 완전히 삭제하기보다 opacity/reveal로 깊이를 이해시키는 것이 우선이다.
3. 근육군 페이지는 구성근을 개별 토글할 수 있게 한다.
4. 관절 위치에 따라 작용이 바뀌는 근육은 하나의 화살표로 고정하지 않는다.
5. 기시/정지 색이 '기시는 고정, 정지는 이동'이라는 잘못된 역학 개념을 만들지 않도록 설명을 둔다.
6. 뼈 이외의 부착(힘줄, 근막, 널힘줄, 중앙힘줄)은 뼈 hotspot과 분리한다.
7. 실제 SVG 완료 후 뼈 랜드마크의 위치는 문서 검수와 별도로 이미지 기준 재검수한다.

## Quiz hotspot

- 정답 판정 영역은 시각적 부착점보다 약간 넓힐 수 있다.
- 라벨 숨김 상태에서도 뼈 윤곽과 시점(R/L, anterior/posterior)은 유지한다.
- 여러 부착점이 정답인 문제는 모두 허용 영역으로 등록하거나 질문을 한 부착점으로 한정한다.
