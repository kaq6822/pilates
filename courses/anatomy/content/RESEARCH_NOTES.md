# Research Sources & Editorial Notes

이 패키지는 첨부 기획서의 콘텐츠 구조를 따르되, 해부학 세부 정보는 주로 NCBI Bookshelf / StatPearls의 해부학 항목을 중심으로 교차 확인하여 재서술했습니다. 일부 개별 근육에 전용 문서가 없는 경우에는 해당 부위의 compartment, nerve, vertebral/foot anatomy 자료를 함께 사용했습니다.

## 주요 공통 자료군

- NCBI Bookshelf / StatPearls — Suboccipital Muscles, Prevertebral Muscles, Neck Movements
- NCBI Bookshelf / StatPearls — Shoulder and Upper Limb / Arm Muscles / Nerves
- NCBI Bookshelf / StatPearls — Thorax / Intercostal anatomy
- NCBI Bookshelf / StatPearls — Back / Vertebral Column / Transversospinalis
- NCBI Bookshelf / StatPearls — Hip, gluteal, adductor and posterior thigh anatomy
- NCBI Bookshelf / StatPearls — Leg compartments, tibial/fibular nerves
- NCBI Bookshelf / StatPearls — Foot Muscles / Foot Joints / Medial Longitudinal Arch

## 편집상 주의

이 자료에서 “필라테스 적용”은 해부학 기능을 운동교육 맥락으로 연결한 설명입니다. 특정 동작의 치료 효과나 특정 근육의 선택적 활성화를 보장하는 문장이 아닙니다. 최종 공개 전에는 사용하는 해부학 일러스트의 라이선스와 한국어 해부학 용어 정책을 별도로 확정해야 합니다.
