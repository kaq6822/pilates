# 근육별 퀴즈 작성 가이드 v3

각 페이지는 **10문항**을 기본으로 한다.

1. 부착점/기시 hotspot
2. 정지 또는 대응 부착점 hotspot
3. 신경지배 회상
4. 대표 기능 회상
5. 과잉 단순화 판별
6. 부하·수정 변수 적용
7. Cueing/관찰 포인트
8. 오개념 참·거짓
9. 대표 관절/분절 움직임 해석
10. Pilates 동작에서 운동 조건 조절

## 교육 원칙

- 여러 구획을 가진 근육은 '대표 기시'를 임의로 하나 고르지 말고 질문에 구획명을 명시한다.
- 갈비사이근처럼 기시/정지보다 연속적인 위·아래 부착 관계가 중요한 구조는 해당 관계를 묻는다.
- 신경근 분절은 자료 간 차이가 있으면 말초신경/직접 가지를 우선 답으로 사용한다.
- 자세나 통증을 특정 근육 하나로 진단하게 하는 문항을 만들지 않는다.
- Pilates 문항은 동작 이름 암기보다 `운동목표 → 요구량 → 수정 변수 → 증상`을 묻는다.
- 객관식으로 변환할 경우 오답도 해부학적으로 그럴듯한 같은 범주의 항목으로 만들고, 실제로 둘 이상 정답이 되지 않는지 별도 검수한다.


## 영어 용어 설명 규칙

- 문제에 영어 해부학·운동학 용어가 등장하면 한국어를 먼저 쓰고 영어를 괄호에 병기한다.
- 학습자가 뜻을 알아야 문제를 풀 수 있는 영어 용어는 문제 바로 아래에 `용어 설명:`을 둔다.
- 예: `가동범위(ROM)`, `내밈(protraction)`, `날개어깨(scapular winging)`.
- `Hotspot`, `Cueing` 같은 인터페이스·문항 유형 이름도 화면에서는 각각 `위치 선택`, `지도 문장`처럼 한국어를 우선한다.
